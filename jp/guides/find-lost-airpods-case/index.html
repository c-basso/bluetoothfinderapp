AirPodsのケースをなくした時の探し方

最終更新日 2026年10月14日

結論

状況によります。AirPodsを入れたままふたを閉じたケースはスリープ状態で信号を出さず、通常の空のケースには自分で信号を出す送信機がありません。ふたが開いていればAirPodsが起動して信号を出すので、Bluetoothスキャンで見つかります。AirPods Pro 2以降とAirPods 4（アクティブノイズキャンセリング搭載モデル）のケースは「探す」に対応しており、スピーカーで音も鳴らせます。

ケースが探しにくい理由

AirPodsのケースは、中のAirPodsを充電するための箱です。旧モデルのケース自体にはBluetooth送信機がなく、ふたを閉じると中のAirPodsもスリープするため、外から検出できる信号はほとんど出ません。

AirPods Pro 2以降と一部の新しいモデルでは、ケース自体に「探す」用の機能とスピーカーが内蔵されています。自分のケースがどのモデルかを確認しましょう。

ケースを探すために使える手がかり

「探す」に対応したケースなら、地図で最後の位置を確認し、近くにあれば「サウンドを再生」でケースを鳴らしましょう。

AirPodsがケースに入っていてふたが開いている、または誰かがふたを開けた場合は、AirPodsが信号を出すので、Bluetooth Finderで検出できます。そうでない場合は、最後にケースを使った場所、バッグやポケット、洗濯物を順に確認するのが現実的です。

  • ふたが閉じていてAirPodsが中にある → 信号なし。最後の場所と定番の場所を物理的に探す
  • ふたが開いている、またはAirPodsがケースの外 → Bluetoothスキャンで検出できる
  • AirPods Pro 2以降のケース → 「探す」で位置確認とサウンド再生が可能

AirPodsのケースを探す手順

  1. 「探す」を確認

    「探す」→「デバイス」で、ケースまたはAirPodsの最後の位置を確認します。対応ケースならサウンドを再生しましょう。

  2. Bluetooth Finderでスキャン

    最後の位置の周辺でスキャンし、AirPodsが一覧に出るか確認します。出たら、ふたが開いているかケースの外にある可能性があります。

  3. ホット・コールドに従う

    一覧に出た場合は、AirPodsを選んで「ベリーホット」になる場所まで進みます。

  4. 定番の場所を探す

    信号がなければ、バッグ、上着のポケット、ソファ、車内、洗濯物を順に確認します。

  5. 交換を検討

    見つからない場合、Appleでケースだけの交換品を購入できます。

ケースの外にあるAirPodsなら、すぐに見つかります。

スキャンしてAirPodsを選び、ホット・コールドに従うだけ。App Storeで無料。

よくある質問

空のAirPodsケースは探せますか？
旧モデルの空のケースは信号を出さないため、Bluetoothスキャンでは探せません。AirPods Pro 2以降のケースは「探す」で探せます。
ケースの中のAirPodsは検出できますか？
ふたが閉じているとAirPodsはスリープし、信号を出しません。ふたが開いていれば検出できます。
ケースだけ購入できますか？
はい、Appleで交換用の充電ケースを購入できます。
